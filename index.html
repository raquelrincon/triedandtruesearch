Tried and True Finder

Two ways to find free products: a keyword search button you add to your bookmarks, or category links below.

Keyword search button

A bookmark that searches the names of every Tried and True free product. It works in Chrome on a computer, while you're signed in to Wayfair.

Set it up once: (if you added an earlier version, delete that bookmark first. This one shows product photos.)

  1. Show your bookmarks bar with Ctrl + Shift + B (Mac: Cmd + Shift + B).
  2. Drag this button onto the bookmarks bar: T&T Search
  3. If dragging doesn't work: tap Copied, then right-click the bookmarks bar, choose Add page, name it T&T Search, and paste into the URL box.

Use it:

  1. Open the Tried and True page and click T&T Search.
  2. A search box opens on the page. The first time, it loads all free products, which takes about 30 seconds.
  3. Type a word and press Search. Results link straight to each product. Later searches are instant until you reload the page.

How this works

Wayfair's rebuilt Tried and True page only filters by Category, Color, Brand, rating and availability. Category links use the new format, ?filters=masterClID%7E6260, where the number is the category. Keyword search links no longer work on the new page. The category list here was copied from the page you saved on October 7, 2026, when it had 7,094 free products. Wayfair adds and removes categories, so a category that appears later won't be here until the list is refreshed.
